# 废品飞船

一款面向 TapTap 的竖屏 H5 增量小游戏：拖动磁铁拆解废品，组建无人机队，研发插件，把回收站里的破烂拼成一艘飞船。

当前已实现本地可玩的完整回收、五章飞船、研发、拆解、重复订单与存档。TapTap MCP 已安装，用户选择稍后授权，真实广告和平台发布尚未执行。功能、视觉和交付状态见 docs/validation 中的实际记录。

运行：`npm ci` 后执行 `npm run dev`。构建：`npm run build`。详细说明见 [本地运行与发布准备](docs/LOCAL_DEVELOPMENT.md)。

本轮交付入口：[最终验收报告](docs/validation/FINAL_REPORT.md)、[实机与概念图对照](docs/validation/visual-comparison.html)、[参考游戏调查](docs/REFERENCE_RESEARCH.md)。

## 当前约束

- 开发预算：8 小时，开发工作计时，不包含平台审批、账号认证和用户扫码等待。
- 付费模式：免费，无内购；通过玩家主动观看激励视频获得广告收入。
- 首轮主线目标约45–75分钟，具体模拟策略和范围以数值报告为准；模拟不冒充真人完整游玩。
- 核心画面：固定竖屏、二维正交回收场、五段飞船组装；不做三维场景或自由建造。
- UI只保留关键数字、短标签与必要广告奖励说明；所有文案不使用中点分隔符。
- 发布资源目标≤10MB，项目硬门槛为低于20,000,000字节；H5后台限制发布前再确认。概念图与文档不进入发布包。
- 广告首版：资金补给、广告清屏、精密拆解、定向研发、离线翻倍、章节／订单追加奖励。
- 视觉目标：锁定概念图与匹配存档状态后，按视觉规范逐屏达到至少 90/100；不以一句主观承诺代替实机对照。

清屏是最新规则：完整观看一次广告，回收当前屏幕的全部废品。没有临时伤害倍率、范围倍率或续时。取消和失败不会清除废品。

2026年10月29日新增七步可跳过引导、醒目的研发装配按钮、开源中文字体及CC0循环音乐。详见[验收记录](docs/validation/ONBOARDING_MEDIA.md)与[素材授权](docs/THIRD_PARTY_ASSETS.md)。
