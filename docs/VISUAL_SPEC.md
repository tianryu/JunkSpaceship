# 视觉规范与概念图验收

## 用户最新约束

当前对照使用01、02的清屏v3版本及03、04的少文字v2版本。v3仅因用户要求把超载改为清屏而更新，旧稿保留。标题不放英文副标题，主屏不放常驻教学句，升级卡只显示图标、短名、等级和价格。所有文字禁用中点分隔符，使用留白或独立徽标。背景压缩为一套静态工业墙面，五章通过共享精灵、染色和飞船层变化实现。详细规则见UI_AND_PACKAGE。

## 视觉方向

午夜蓝工业回收站，暖黄色磁铁、无人机与飞船，青色电流和科技反馈。采用二维插画精灵加程序化界面，固定正交视角。已有概念图带有轻量金属纹理、倒角和工厂背景，因此开发必须复用或匹配这些素材，不能仅用无纹理矩形替代后宣称相似。

目标是四种实际游戏状态的统一风格，不是四张不同风格的宣传海报。首版实现中所有中文、金额、概率、按钮和进度均为真实可更新界面，不能烘焙进整张背景。

## 画布与区域

第一张生成文件为 941×1672 像素，接近 9:16。UI 开发采用 360×640 逻辑坐标；对照截图统一使用该逻辑尺寸的整数倍。原图在对照工具中整体等比适配，允许不到 0.1% 的比例差，禁止各区单独拉伸。

参考原图实际区域，而不是仅依照生成提示词的期望坐标：

| 区域 | 逻辑坐标 x/y/w/h | 内容 |
| --- | --- | --- |
| 标题 | 5 / 0 / 350 / 32 | 标识、游戏名、设置 |
| 资金栏 | 5 / 34 / 350 / 29 | 金额、自动产能、加号 |
| 飞船装配区 | 5 / 66 / 350 / 96 | 章名、贡献进度、分层飞船 |
| 回收区 | 5 / 167 / 350 / 240 | 废品、磁铁、无人机、粒子 |
| 升级区 | 5 / 412 / 350 / 151 | 标题、两列卡片；滚动查看更多 |
| 底部导航 | 5 / 568 / 350 / 57 | 升级、研发、仓库、补给 |
| 底部余量 | 0 / 625 / 360 / 15 | 安全区 |

研发／仓库抽屉覆盖回收区和升级区，下沿停在底部导航上方；保持上方飞船上下文和原有导航。抽屉精确坐标以各参考图为准，完成后记录到截图基准。

实现采用整张360×640画布等比适配，长屏和宽屏居中保留余量，避免不同机型改变已验收布局。iPhone 刘海和底部安全区需单独处理；视觉验收用无设备外壳的固定视口。

2026年10月29日按用户要求，字体改为可分发的寒蝉全圆体3.0子集（内部名称 Scrap Round），public/fonts内保留OFL许可证，文件哈希进入包体审计。主标题粗黑，UI 名称粗体，说明常规。数字采用等宽数字特性，防止余额变化让界面抖动。字体文件必须本地可用，不能依赖外网临时加载。

逻辑字号初稿：标题22、资金20、主要页标题18、卡片名称13、正文12、次要说明10–11。最终以 360 宽手机实测可读性微调；不使用小于10的关键奖励文字。

圆角4–8、边框1–2逻辑像素，按钮带轻量明暗层次。主要操作命中区域至少44逻辑像素高；较矮的可见按钮扩大透明命中区域，不与相邻动作重叠。辅助设置与信息按钮受参考顶栏限制，为32至39像素，留待真机触控复核；不宣称全部辅助按钮达到44×44。

## 素材交付要求

实施使用以下独立素材：

1. 无文字的空工厂和回收场地合成一套可分区取样的背景，优先只用1张。
2. 螺丝、螺母、铁片、机器、电池至少5种透明精灵；角度变体通过旋转与缩放获得。
3. 磁铁和无人机透明精灵；清屏仅增加程序化短扫光。
4. 飞船骨架、船舱、引擎、导航、核心四种共享图像加程序化部件状态，锚点相同。
5. 六个插件图标和四个导航图标，遵循固定线宽。
6. 标识图形可作素材；所有动态文字由代码绘制。

资产制作以01号主图为视觉参考，优先用同源图提取／编辑，减少重新绘制产生的差异。透明提取须检查边缘和阴影。项目素材存入 public/art，不能仅引用生成工具的全局目录。

实施已生成public/art/skin.png与sprites.png。前者为空白工业外框，后者是独立透明对象图集；所有交互元素实时绘制。完整提示词见concepts/IMPLEMENTATION_PROMPTS.md。

## 可复现的对照状态

| fixture | 必须设置的状态 |
| --- | --- |
| early | 第一章；一台无人机；磁铁位于左下；24–32件固定种子废品 |
| clear_screen | 第四章；四台无人机；清屏就绪；对应飞船部件；固定种子与采样时刻 |
| research | 打开研发；2次机会；六插件候选；选中电弧；三槽展示 |
| salvage | 打开仓库；3个第一章机匣；普通失败计数1；补偿800 |

仅开发构建可使用 fixture，正式构建移除调试入口。fixture 通过真实状态模型生成界面，不能把整张概念图铺到 Canvas 假装实机。固定随机种子、时钟、视口、字体加载和动画采样时刻后截图。

数字可以与经济调参后结果不同；对比时仅遮罩数值字形。章名、概率、广告标识、按钮名与主要图标不得遮罩。不可遮罩整个回收区或替换真实运行状态。

## 至少90%相似度如何验收

这里把用户要求转换为可审查的逐屏100分量表。它是项目验收规则，不声称某个图像算法能证明人类观感恰好90%。四张图都必须达到90分，不能用平均分掩盖一个明显不同的页面。

| 维度 | 分值 | 检查内容 |
| --- | ---: | --- |
| 布局与比例 | 30 | 六大区位置、卡片网格、按钮与留白；主要锚点偏移≤4逻辑像素，主要尺寸偏差≤5% |
| 精灵与环境 | 25 | 磁铁、无人机、机器、飞船的轮廓、色块、材质和比例；不得换成通用图标占位 |
| 配色与面板 | 15 | 主色、描边、背景层次、圆角与明暗一致 |
| 字体与信息层级 | 15 | 字重、字号、数字格式、标题和次级说明对齐；关键文字没有裁切 |
| 状态与交互外观 | 10 | 插件选中、广告标识、进度条、清屏入口、普通／广告双按钮 |
| 特效 | 5 | 电弧、吸附路径、发光半径和粒子密度；不能遮挡操作 |

每一维先列细项，各细项记完全匹配1、轻微偏差0.5、明显不符0，再乘权重；验证报告附截图与逐项理由。额外硬门槛：主要素材或整块界面缺失、看不清广告奖励、用整图假界面、关键按钮不可点，任一项出现即不通过。

工具辅助：50%透明叠图检查位移；差异热图检查遗漏；静态区域SSIM作为诊断参考。动态粒子与变化数字的遮罩区域总计不得超过画面的10%，遮罩清单必须随报告保存。SSIM不取代上述体验与真实性检查。

视觉对比在P0、P3、P6各做一次。P0对主屏布局，P3对四屏，P6记录最终分数。最终实机截图、比对和评分记录在validation中；测试图明确区分开发fixture和正常生产页面。

## 2026年10月29日飞船追加要求

用户明确要求不同大阶段使用不同皮肤，因此飞船造型区域新增参考 concepts/ships-atlas-v1.png，其余界面继续对照原四屏。一张透明图集包含五章船型和最终曙光号。顶部位置与占位保持，章节进度控制彩色船体逐步显示；点飞船打开图鉴。新手提示、字体及装配主按钮同属本次用户指定调整。新截图和原历史评分分别保存，不将造型更新描述为逐像素复刻。
