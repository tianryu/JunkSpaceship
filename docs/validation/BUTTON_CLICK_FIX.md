# 按钮点击丢失修复

日期：2026年10月29日。版本：0.1.0按钮修订。

用户反馈按钮有时需要点多次。独立内存fixture中复现：磁力等级为3且资金充足，点击图标、名称与价格区域后等级没有变化，排除了余额不足。

## 原因

旧升级卡的真实button只有价格部分，通过绝对定位伪元素把命中范围扩大到整张卡片。按下时button的transform改变了伪元素的定位参照，使扩展命中区域收缩。HUD同时每200ms用innerHTML重建价格内部节点，容易令按下和松开对应不同节点。

## 修复

- 整张168×54升级卡改为真实button，价格仅是内部展示元素，删除跨容器的伪元素命中层。
- 升级卡只初始化一次，购买与HUD刷新均复用节点。价格和等级仅在值变化时更新。
- 按钮内部图标和文字不单独接收指针事件，事件统一落到按钮。
- 按下反馈改为亮度变化，按钮位置固定。所有按钮拥有稳定的相对定位参照。
- 设置与资金入口的扩展命中区域分开，避免边缘重叠。
- 使用原生click与button键盘行为，保留滚动取消和一次点击一次动作，不用pointerdown提前发奖或购买。

## 实际验收

桌面IAB，360×640 CSS视口，独立fixture，不改玩家正常存档。使用真实鼠标输入而非脚本派发click事件。

| --- | --- |
| 图标、名称、价格、左上角、右下角、留白六位置 | 全部成功 |
| 每位置80、300、650ms按压，覆盖多个200ms刷新周期 | 18/18一次点击升一级 |
