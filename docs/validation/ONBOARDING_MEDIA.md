# 新手引导、字体音乐与装配入口验收

日期：2026年10月29日。属于初次本地交付后的用户追加修改，不重新计算原交付的墙钟预算。

## 实施顺序与标准

| 阶段 | 实施 | 通过标准 |
| --- | --- | --- |
| 1 授权和资源 | 下载官方字体及作者发布的音乐，保留许可 | 允许用于包含广告的游戏；完整许可随包；无在线素材依赖 |
| 2 新手引导 | 七步进度、目标边框、跳过、设置重看 | 真实操作推进；跳过不赠送资源、不绕过广告解锁；不拦截回收和升级按钮 |
| 3 装配入口 | 整行48px高主按钮，显示插件名和插槽状态 | 可装配为金色；已装配可卸下；未获得与满槽有明确原因；一次点击生效 |
| 4 音乐 | 首次交互启动，单曲循环，独立开关与暂停 | 首次交互前无audio元素；开关即时生效；广告中暂停、结束恢复；刷新保存偏好 |
| 5 字体与版式 | 游戏字符子集，完整字形检查，多视口检查 | 汉字无缺字和空轮廓；主按钮及核心文案无溢出；仍使用原界面结构 |
| 6 交付 | 回归测试、构建、包体及ZIP完整性检查 | 39项规则测试通过；首屏<3MB；运行资源≤10MB；ZIP和解压各<20MB |

## 操作规则

1. 按住并拖动回收3件废品。单纯按下不完成此步。
2. 回收攒够10资金，点击磁力卡完成首次磁力升级。
3. 攒够120资金，购买第一台无人机。
4. 打开研发，提示每80件获得研发机会。
5. 指向装配主按钮，说明最多3槽、有空位自动装配及更换入口。
6. 打开仓库，说明每20台机器获得机匣。
7. 指向飞船，说明100%安装、集齐5件起航，点击“出发”完成。

跳过和完成持久化保存。设置中重看会根据已有回收、磁力和无人机进度略过已完成的操作，不重置航程。引导没有动画，没有全屏阻挡层，卡片仅关闭和继续按钮接收点击。弹窗和广告期间隐藏引导。

## 验收证据

- 新手真实回收从0件到3件后进入第2步；资金不足提示差额；资金达到12后高亮磁力；一次点击扣至2并进入第3步。
- 无人机资金门槛、购买后推进、旧存档迁移、跳过不解锁广告均通过独立规则测试。
- 重看引导完成研发、装配说明、仓库、飞船和结束，详见 guide-ui-check.json。
- 装配按钮650ms真实按压一次成功；装配、卸下、满槽、未获得四状态通过，详见 equipment-cta-check.json。
- 音乐真实媒体元素就绪并循环，设置关闭后 paused=true，再开启恢复；模拟广告中暂停、完成后恢复，且始终只有一个audio元素，详见 music-ui-check.json。
- 音频完整解码成功，约69.90秒，峰值低于0dBFS；未把解码检查描述为真人听感测试。
