## 功能范围

按住或拖动磁铁回收三类废品，六项升级、最多六台无人机、电池连锁与免费脉冲；五章贡献与飞船装配；六插件、三槽、随机和定向研发；35%普通拆解、连续三次失败后的保底、广告必得核心；十二秒发射结局与重复订单；本地存档、离线结算、静音和减少特效。

清屏已完全替代超载。完整观看后按冻结的在场对象逐件结算，计入资金、章节、研发、机匣与适用订单进度，再清除这些对象。取消和失败不清屏，不消耗机匣或研发机会；重复回调不能再次发奖。资金与清屏入口常驻，概率玩法可通过主动看广告获得明确的100%结果。
