正常主动策略每10秒使用磁铁4秒，其余时间依靠自动化；理想路线始终即时瞄准最弱目标，是操作上界。所有路线每2秒按固定优先级尝试购买设备，并使用已获研发与机匣资源。界面停留时间未模拟，因此不能把结果视作每位玩家的精确通关时间。

广告墙钟时间按每次30秒估算，实际广告长短与供给由平台决定。高频看广告能减少作业时间，但观看本身耗时，总会话可能更长。清屏仅回收本屏真实对象，不伪造多倍贡献。

正常无广告路线应落入45–75分钟目标区间；自动路线允许更慢，理想持续操作允许更快。全部路线必须能结束主线且保持有限非负资金。
