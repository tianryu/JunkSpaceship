## 差异和扣分原因

01：背景与主要分区锚点一致。无人机位置由真实选敌决定，废品分布和数量来自固定随机种子的生成器，并未照抄每件道具位置。磁铁和飞船复用同源图集，但轮廓细节并非逐像素一致。升级等级改为短名称下方，避免后期长价格挤压；这项有意改变已扣字体分。没有伪造截图里的浮动收益。

02：真实第四章的机器比例更高，画面比参考图更密集；无人机按真实目标运动，未为截图强制站到四角。用同一机匣的程序染色提供绿色变体。清屏按钮和广告标识完整，无旧超载时间条。少用装饰粒子，效果项扣分。

03：六卡、三槽、选中态、随机与必得按钮均存在。插件等级、装备文案来自模型，不能为复制参考数字制造互相矛盾的状态。插件图标采用少量SVG和同一图集，切割与分拣图标细节较简化。为保证按钮44像素高度，底部动作区相对参考略有调整。

04：机匣、35%与100%并列选择、保底进度、普通补偿和广告声明均完整可见。机匣正面细节和底座光与参考有差异，核心精灵使用同图集。永久强化位于抽屉下方，可滚动访问；不为复制参考图而删除真实玩法。修复了首次检查发现的右侧横向溢出。

## 适配检查

360×640、390×844、412×915下分别检查四屏，共12组，主容器全部无横向溢出，字体均已加载。长屏整体等比居中，保留上下余量。安全区通过系统env变量参与缩放。此结果属于桌面浏览器视口验证，iOS和Android实体机仍需授权后实测。

升级卡整张可点击，清屏、核心强化、拆解、研发动作和导航有至少44逻辑像素的主要命中高度；小型设置和说明按钮遵循参考顶栏尺寸，约32至39像素，作为已记录的辅助控件差异留待真机触控复核。
