# 功能与发布验收清单

版本0.1.0，2026年10月28日。本地可执行项已按下列证据勾选；实体手机、真实广告和发布项保持未勾选。34项单元测试、24项浏览器广告模拟、12组视口检查、共享引擎通关模拟、生产包实测和逐屏视觉报告均在validation内。

## 核心玩法

- [x] 鼠标真实拖动与按住拆解通过，统一Pointer Events输入处理离区、取消与失焦。
- [ ] 实体手机触摸拖动、系统返回与切后台恢复实测。
- [x] 一件废品被磁铁、无人机、连锁同时击中时只发一次钱。
- [x] 无人机最多6台；敌人死亡后不会持续追踪失效目标。
- [x] 电池连锁去重、有深度上限，不无限递归。
- [x] 六项升级的等级、成本、最大购买与章节上限正确。
- [x] 购买资金不足或达到上限时不扣款、不出现负数。
- [x] 无广告路径可完成五章与发射；广告直接资金不直接增加章节贡献。
- [x] 章节转换只执行一次，无双生成器或重复部件奖励。
- [x] 主线结束可继续订单，订单目标在开始时冻结。

## 概率与研发

- [x] 普通拆解35%使用真实配置；测试使用可注入随机源检查成功／失败边界。
- [x] 连续三次失败后下一次普通必得，成功后清零；广告不改变普通保底。
- [x] 普通保底已生效时不显示“付出广告换同样必得”的冗余入口。
- [x] 普通失败获得承诺的资金补偿，且只消耗一个机匣。
- [x] 随机研发只从未满级集合均匀选择，面板概率与集合一致。
- [x] 定向研发给指定插件，广告中断不扣机会。
- [x] 三插槽不允许重复插件；更换后效果即时且不会多叠一次。
- [x] 全部满级后正确兑换研发机会，没有空集合随机异常。

## 六场景广告矩阵

浏览器逐场景覆盖完整、取消、不可用、异常，共24组。单元测试覆盖六场景重复回调、双击和刷新资源保存，以及SDK加载／显示失败分支。平台原生广告遮罩与切后台需要真机验证。

- [x] 仅明确 isEnded=true 发广告奖励。
- [x] show() Promise 成功不会发奖。
- [x] 一个广告完成只结算一个 rewardId。
- [x] 先保存消费与发奖快照，再展示奖励动画。
- [x] 已显示金额、指定插件和机匣目标在播放期间保持不变。
- [x] 无填充恢复正常操作，不扣资源、不进入无限请求循环。
- [x] 普通离线收益不因广告失败消失。
- [x] 清屏只回收冻结时的对象；完整观看后一次发奖；取消不清场；新增废品不被重复回调清除。
- [x] 广告冷却、可用性和返回正常游戏状态在重进后合理恢复。
- [x] 正式包编译移除模拟广告与fixture，实际URL带测试参数仍为正常新游戏。
- [ ] 至少一轮真实TapTap广告完整、取消和错误恢复验证。
